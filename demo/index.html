k-mix-api 2.0 demo

Full Web MIDI control of the KMI K-Mix — powered by k-mix-api (on midi-ports for topology & hot-plug)

idle

No K-Mix attached? The page still loads and shows the API — sends will warn until the Control Surface / Audio Control ports appear. Put K-Mix in a MIDI Bank mode (shift + a numbered transport button) to receive control events.

Connection — kmix.isConnected(port)

Updates live on connected/disconnected events and raw port state changes.

Send to K-Mix — kmix.send(control, value[, bank])

Audio Control — input channels send('fader:N', v) · send('mute:N', 0|127)

Audio Control — main & misc

main fader 100 send('main:fader', v)
reverb level 64 send('misc:reverb-level', v)
preset send('preset', n) — program change

Control Surface — button LEDs send('control:<name>', 1|0, bank)

bank

Raw bytes send([status, data1, data2]) → Audio Control out

e.g. 176, 1, 127 = CC1 on ch1

Inbound events — kmix.on('any', …)
